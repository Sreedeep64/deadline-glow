# Deadline Glow

Deadline Glow turns an important deadline into a polished phone lock screen. Set an event, date, focus note, and three short milestones, then download a 1290 × 2796 PNG wallpaper.

## Features

- Live days, hours, minutes, and seconds countdown
- Three visual themes designed around lock-screen readability
- Ordered milestone plan leading up to the deadline
- Quick date presets and browser-saved settings
- Phone-sized PNG download generated locally in the browser
- Responsive, keyboard-accessible interface

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
